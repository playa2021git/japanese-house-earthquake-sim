# japanese-house-earthquake-sim

単一HTMLファイルで完結する、日本家屋の軸組（柱・梁・筋交い）の耐震性を見せる教育用の疑似物理シミュレーターです。
v1.0でゼロから作り直し、**2Dで筋交いを設置・交換・撤去 → 地震シミュレーションは3Dで実行**する構成になりました。

## 使い方

`index.html` をブラウザで直接開くと動作します。外部ライブラリ、外部CSS、外部画像、ビルドツールは不要です。

1. 左の「①筋交いエディタ」で「前後面」「左右妻」の2タブを切り替え、マス目をクリックして筋交いを
   なし → ／ → ＼ → Ｘ → なし の順で設置・交換・撤去します。前後面タブは前面と背面に、左右妻タブは
   左妻と右妻に、それぞれ同じ配置が自動的にミラーされます（4面バラバラではなく2セットとして編集）。
2. 右の「③震度と操作」で震度を選び、「開始」を押すと中央の「②3Dシミュレーション」に切り替わり、①の配置のまま
   3次元的に加振します。ドラッグで視点回転、ホイールでズームできます。
3. 「編集モードに戻る（リセット）」でいつでも配置をやり直せます（筋交いの配置自体は保持されます）。

## v1.3（クリア演出・効果音・倒壊アニメ・震度の目安表示）で変えたこと

- 「10秒クリア」時の「再開」ボタンが目立たなかったため、クリアした瞬間から緑色・大きめサイズ・脈動する
  アニメーション付きの見た目に変えました（`.clear-highlight` クラス）。編集モードに戻る、または開始し
  直すと元の見た目に戻ります。
- Web Audio API で、外部音声ファイルなしに揺れの強さに応じた地鳴り風の効果音を追加しました。ノイズを
  ブラウンノイズ寄りにフィルタしたループ音源を1本作り、`excitationLevel`（揺れの強さ 0〜1）に応じて
  音量とローパスフィルタの周波数を動かしています。倒壊が確定した瞬間には短いドスンという音も鳴ります。
  「揺れの効果音を鳴らす」のチェックボックスでオフにできます（自動再生ポリシーの都合上、実際の再生開始は
  「開始」ボタンのクリック時に行われます）。
- 倒壊判定が出た瞬間に画面が止まっていたのを、**倒壊後も約1.6秒かけてぺしゃんこに潰れるところまで**
  表示するようにしました。最初は物理演算（PBD拘束）をそのまま倒壊後も弱めて回す方式を試しましたが、
  部材同士が矛盾した力を出し合い「潰れたあとに軽く浮き上がる／バタつく」という不自然な挙動になったため、
  **倒壊が確定した瞬間の姿勢をスナップショットし、そこから各ノードのY座標だけをイーズアウトで地面近くまで
  一方向に下げる**、位置アニメーション方式に変更しました（`startCrumble()` / `crumbleStep()`）。
  X・Z座標は倒壊確定時点のまま固定するため、横方向の動きやバウンドは発生せず、上から下に潰れて完全に
  静止します。倒壊の瞬間の地震動・効果音（地鳴り）もここで止まり、代わりに短いドスン音が鳴ります。
  `window.__test.runHeadless()` は従来通り一発で判定のみ返す高速な検証用フックのままです。
- 「③震度と操作」の震度5強以上のボタンにマウスを乗せると、その震度クラスの目安として実際に観測された
  地震の例（2021年千葉県北西部の地震＝震度5強、2018年大阪府北部地震＝震度6弱、2019年山形県沖の地震＝
  震度6強、阪神・淡路大震災／東日本大震災／2024年能登半島地震＝いずれも震度7）をツールチップで表示する
  ようにしました。

## v1.2（疲労蓄積・クリア判定）で変えたこと

- これまで筋交いは「一発で許容ひずみを超えた分」しかダメージが進まず、全ベイX字配置（最強構成）で震度7を
  与えても、瞬間的なひずみが許容値を超えないため**理論上いつまでも倒壊しない**という不自然な挙動でした。
  実際の木造住宅は許容値ぎりぎりの揺れに繰り返しさらされると、金物や仕口が少しずつ緩んで弱っていくため、
  筋交いに**疲労蓄積**（許容ひずみ以内でも、応力比が一定以上の状態が続くと少しずつダメージが進む・
  `updateDamageAndStress()` 内、応力比の3乗に比例して進行）を追加しました。
- 上記の疲労により、全ベイX字配置でも震度7を浴び続けると約17〜18秒ほどで倒壊するようになりました
  （震度6強以下では、全ベイX字配置なら疲労はほとんど進みません＝日常的な地震には強いままです）。
  柱・梁自体は従来どおり破断しない設計のままです（疲労の対象は筋交いのみ）。
- 「③震度と操作」で開始し、**倒壊せずに10秒間耐えると自動的に一時停止し「耐えた！（10秒クリア）」と
  表示**するクリア判定を追加しました（`CLEAR_TIME` 定数）。そのまま「再開」を押せば、震度7の全ベイX字
  配置のように、10秒より先に疲労で倒壊するかどうかも引き続き確認できます。
- `window.__test.runHeadless()` は従来どおり指定秒数まるごとシミュレートするテスト用フックのままで、
  10秒クリアによる自動停止の影響を受けません（自動停止はリアルタイム表示側のみの挙動です）。

## v1.1（見た目の家らしさ向上）で変えたこと

- 骨組みだけだった3Dモデルに、**切妻屋根（棟木・軒の出・けらばの出のある2面勾配屋根）**と、**土台・1階床・
  2階床の板張り床（目地入り）**を追加しました。屋根・床は2階梁の現在位置から毎フレーム再計算しているため、
  加振で揺れたり倒壊で傾いたりすると屋根・床もそれに追従して変形します。
- 筋交いエディタは「前面・背面・左妻・右妻」の4面バラバラの編集から、「前後面」「左右妻」の2セットに
  まとめました。片方の面を編集すると対になる面（前⇔背、左⇔右）にも自動的に同じ配置が適用されるため、
  筋交いのある家／ない家のような左右対称の比較がしやすくなっています。
- これに伴い、内部テストプリセット③は「3方向だけX字配置（背面だけ無筋交い）」から「前後面だけX字配置
  （左右妻は無筋交い）」に変更しました。個々の面ではなく前後面／左右妻という軸単位の偏りを再現します。

## v1.0（3D化）で変えたこと

- v0.6までの「平面1枚・評価ロジックで減点する」方式をやめ、**柱4本以上・2スパン×1スパン・2階建ての3D軸組**
  （X方向2スパン、Y(奥行き)方向1スパン、柱6本×3層）に作り直しました。壁の筋交い設置枠（ベイ）は前面4・背面4・
  左妻2・右妻2の計12箇所です。
- 物理は3D Verlet積分＋距離拘束（PBD風）で、`evaluateBraceLayout()` のような「左右偏り・片側偏りを点数化して
  減点する」ロジックは廃止しました。偏った配置がねじれて壊れやすいのは、3次元的な剛性の偏りから**自然に**
  発生する挙動です。
- 各階の床には常設の水平構面（火打ち・面材床に相当）を入れ、床が平面内でほぼ剛体として動くようにしました。
  これにより、一方の壁だけ筋交いを入れた家は、剛心と重心のズレでねじれながら壊れる挙動が物理的に再現されます。
- 筋交いは引張と圧縮で強さが非対称（座屈を簡易的に表現）です。片筋交いは圧縮側で弱く、繰り返し加振で徐々に
  ダメージが蓄積して破断しますが、X字筋交いは常にどちらかの筋交いが引張側で効くため強く残ります。
- 柱・梁だけの四角形骨組み（筋交いゼロ）は、ピン接合のトラスとして水平方向の剛性がゼロになるため、
  **震度1でも時間とともに倒壊します**（内部テストのシナリオで確認済み。詳細は次項）。
- 描画は引き続き外部ライブラリなし・Canvas 2Dの自前投影（正射投影＋ドラッグでの視点回転）です。3D化しても
  単一HTML・オフラインという方針は変えていません。
- `window.__test.runHeadless(震度, 秒数, モード)` などのテスト用フックを用意し、Playwright等のヘッドレス
  ブラウザから配置と震度を変えて自動検証できるようにしました（本番UIには影響しません）。

## 教材のポイント（内部テストの4プリセット）

1. **筋交いなし**：柱と梁だけの四角形骨組みは、震度1でも横揺れに対して抵抗がゼロなので、時間とともに傾きが
   蓄積し倒壊します。
2. **2階だけX字配置（1階が弱い）**：1階が無筋交いだと、2階を固めても1階に変形が集中して倒壊します
   （現実の「ピロティ崩壊」に相当）。
3. **前後面だけX字配置（左右妻は無筋交い）**：前後面と左右妻で耐震性能に偏りがあると、剛心と重心が
   ズレ、震度5強あたりから損傷が目立ち始め、震度7では明確な損傷が出ます（倒壊はしません）。
4. **全ベイX字配置**：4面すべてをバランスよくX字配置にすると、震度7でも層間変形・筋交いの負荷は小さく
   安定します。

## v0.6までにあった「震度1でも長時間加振で危険」という表現について

v0.6のREADMEには「震度1でも長時間加振で危険になり得る」という記述がありましたが、この模型は疲労破壊を
扱っておらず、物理的に説明が難しい表現でした。v1.0では、震度と加振継続時間はプリセットに従った現実的な
範囲にとどめ、「震度1でも“無筋交いなら”倒壊する」という、筋交いの有無そのものが結果を左右する挙動に
絞っています。

## 実装方式

Vanilla JavaScriptとCanvas 2Dだけで、3D Verlet積分＋距離拘束（PBD風）の疑似物理を実装しています。
有限要素法や建築基準法の厳密な壁量計算・許容応力度計算ではなく、教育用に「筋交いの有無・配置バランスが
結果を左右する」という方向性が分かるための疑似物理です。
