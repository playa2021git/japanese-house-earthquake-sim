# japanese-house-earthquake-sim

単一HTMLファイルで完結する、日本家屋の軸組（柱・梁・筋交い）の耐震性を見せる教育用の疑似物理シミュレーターです。
v1.0でゼロから作り直し、**2Dで筋交いを設置・交換・撤去 → 地震シミュレーションは3Dで実行**する構成になりました。

## 使い方

`index.html` をブラウザで直接開くと動作します。外部ライブラリ、外部CSS、外部画像、ビルドツールは不要です。

1. 左の「①筋交いエディタ」で壁面タブ（前面・背面・左妻・右妻）を切り替え、マス目をクリックして筋交いを
   なし → ／ → ＼ → Ｘ → なし の順で設置・交換・撤去します。
2. 右の「③震度と操作」で震度を選び、「開始」を押すと中央の「②3Dシミュレーション」に切り替わり、①の配置のまま
   3次元的に加振します。ドラッグで視点回転、ホイールでズームできます。
3. 「編集モードに戻る（リセット）」でいつでも配置をやり直せます（筋交いの配置自体は保持されます）。

## v1.0（3D化）で変えたこと

- v0.6までの「平面1枚・評価ロジックで減点する」方式をやめ、**柱4本以上・2スパン×1スパン・2階建ての3D軸組**
  （X方向2スパン、Y(奥行き)方向1スパン、柱6本×3層）に作り直しました。壁の筋交い設置枠（ベイ）は前面4・背面4・
  左妻2・右妻2の計12箇所です。
- 物理は3D Verlet積分＋距離拘束（PBD風）で、`evaluateBraceLayout()` のような「左右偏り・片側偏りを点数化して
  減点する」ロジックは廃止しました。偏った配置がねじれて壊れやすいのは、3次元的な剛性の偏りから**自然に**
  発生する挙動です。
- 各階の床には常設の水平構面（火打ち・面材床に相当）を入れ、床が平面内でほぼ剛体として動くようにしました。
  これにより、一方の壁だけ筋交いを入れた家は、剛心と重心のズレでねじれながら壊れる挙動が物理的に再現されます。
- 筋交いは引張と圧縮で強さが非対称（座屈を簡易的に表現）です。片筋交いは圧縮側で弱く、繰り返し加振で徐々に
  ダメージが蓄積して破断しますが、X字筋交いは常にどちらかの筋交いが引張側で効くため強く残ります。
- 柱・梁だけの四角形骨組み（筋交いゼロ）は、ピン接合のトラスとして水平方向の剛性がゼロになるため、
  **震度1でも時間とともに倒壊します**（内部テストのシナリオで確認済み。詳細は次項）。
- 描画は引き続き外部ライブラリなし・Canvas 2Dの自前投影（正射投影＋ドラッグでの視点回転）です。3D化しても
  単一HTML・オフラインという方針は変えていません。
- `window.__test.runHeadless(震度, 秒数, モード)` などのテスト用フックを用意し、Playwright等のヘッドレス
  ブラウザから配置と震度を変えて自動検証できるようにしました（本番UIには影響しません）。

## 教材のポイント（内部テストの4プリセット）

1. **筋交いなし**：柱と梁だけの四角形骨組みは、震度1でも横揺れに対して抵抗がゼロなので、時間とともに傾きが
   蓄積し倒壊します。
2. **2階だけX字配置（1階が弱い）**：1階が無筋交いだと、2階を固めても1階に変形が集中して倒壊します
   （現実の「ピロティ崩壊」に相当）。
3. **3方向だけX字配置（背面だけ無筋交い）**：4面のうち3面を固めても、残り1面が無筋交いだと剛心と重心が
   ズレ、震度5強あたりから損傷が目立ち始め、震度7では明確な損傷が出ます（倒壊はしません）。
4. **全ベイX字配置**：4面すべてをバランスよくX字配置にすると、震度7でも層間変形・筋交いの負荷は小さく
   安定します。

## v0.6までにあった「震度1でも長時間加振で危険」という表現について

v0.6のREADMEには「震度1でも長時間加振で危険になり得る」という記述がありましたが、この模型は疲労破壊を
扱っておらず、物理的に説明が難しい表現でした。v1.0では、震度と加振継続時間はプリセットに従った現実的な
範囲にとどめ、「震度1でも“無筋交いなら”倒壊する」という、筋交いの有無そのものが結果を左右する挙動に
絞っています。

## 実装方式

Vanilla JavaScriptとCanvas 2Dだけで、3D Verlet積分＋距離拘束（PBD風）の疑似物理を実装しています。
有限要素法や建築基準法の厳密な壁量計算・許容応力度計算ではなく、教育用に「筋交いの有無・配置バランスが
結果を左右する」という方向性が分かるための疑似物理です。
